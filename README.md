# Dominó Manauara

Dominó em duplas com as regras de Manaus: bucho, garagem, passe e galo.
Jogo para celular que funciona no navegador, pode ser instalado na tela de início e roda até sem internet.

- `index.html`: o jogo inteiro
- `sw.js`: guarda o jogo no celular para funcionar offline (troque o número da versão a cada atualização)
- `manifest.webmanifest`, `icons/`: nome e ícone do app
- `privacidade.html`: política de privacidade
- `fonts/`: Alfa Slab One e Figtree (licença SIL OFL, arquivos em `fonts/`)
